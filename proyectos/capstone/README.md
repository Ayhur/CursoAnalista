# Capstone - Análisis de principio a fin

## Reto

Elige un problema realista: conversión de un producto, demanda de un negocio, retención, eficiencia operativa o desigualdad en un servicio. Usa un dataset con licencia y documenta su procedencia.

## Entregables

1. README ejecutivo con pregunta, decisión y recomendación.
2. Diccionario de datos, procedencia y evaluación de calidad.
3. Análisis reproducible en Python y/o SQL.
4. Métricas definidas y visualizaciones explicativas.
5. Limitaciones, riesgos y próximos pasos.
6. Presentación de cinco diapositivas para público no técnico.
