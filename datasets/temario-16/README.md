# Datos del bloque 16

`operaciones.sqlite` se crea al ejecutar `notebooks/practicas/16-informe-operaciones.py`. Es una base SQLite didáctica, sin datos personales, con una fila por intento de cobro. El script no la sube al repositorio: permite practicar una extracción parametrizada y repetir el laboratorio.

En una empresa, la fuente sería una base con permisos de solo lectura y retención gobernada. No copies credenciales ni datos personales a este directorio.
