# Dataset del bloque 01

Datos didácticos ficticios de Mercado Faro. `pedidos.csv` incluye a propósito un duplicado, una fecha ausente y un canal no incluido aún en el contrato para que el laboratorio no oculte los problemas. `lineas_pedido.csv` permite observar el cambio de grano de pedido a línea. `pedido-ejemplo.json` ilustra un pedido con lista de artículos.

No contiene datos reales ni PII.
