# Solución - Elegir gráfico

1. Línea temporal; barras apiladas diarias dificultarían ver tendencia. 2. Histograma o caja; una línea implica orden temporal inexistente. 3. Funnel o barras ordenadas; un pastel hace difícil comparar pérdidas. 4. Dispersión con tendencia; barras ocultan la relación entre dos variables continuas.
