# Rúbrica del capstone

| Área | Qué se evalúa |
| --- | --- |
| Pregunta | Es concreta, relevante y conecta con una decisión. |
| Datos | Origen, licencias, grano, calidad y limitaciones documentados. |
| Método | Transformaciones reproducibles y validaciones razonables. |
| Razonamiento | Diferencia observación, inferencia e incertidumbre. |
| Comunicación | Gráficos honestos, recomendación clara y audiencia considerada. |
| Ética | Privacidad, sesgos y posibles daños reconocidos. |
