# Diagnóstico inicial

No tiene nota. Sirve para decidir qué revisar y qué puedes avanzar más rápido.

1. ¿Puedes distinguir media y mediana y explicar cuándo elegirías cada una?
2. ¿Puedes leer una tabla y detectar una fila duplicada?
3. ¿Has escrito una función o una consulta SQL alguna vez?
4. ¿Puedes explicar la diferencia entre una métrica y un KPI?
5. ¿Dispones de móvil, ordenador o ambos para las prácticas?

Si ya tienes una base fuerte de matemáticas, marca el bloque 03 como "diagnóstico pendiente" y retoma únicamente sus aplicaciones al análisis.
